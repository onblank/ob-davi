# OB-DaVi 1.0 Scope

1. Portable `.obdavi` DuckDB project.
2. File adapters: Excel, CSV/TSV, JSON/JSONL/NDJSON, Parquet, Arrow/Feather, text PDF, SQLite, DuckDB.
3. DB connectors: PostgreSQL, MySQL/MariaDB, SQL Server.
4. Multi-object discovery/import and preview.
5. Type/schema inference and manual correction.
6. Snapshot refresh with schema-drift workflow.
7. Rich non-destructive data preparation pipeline.
8. Dataset relationships and validation.
9. Calculated columns and measures.
10. Pivot table engine and pivot-based charts.
11. Full v1 chart catalog documented in `VISUALIZATIONS.md`.
12. Multi-dashboard canvas builder.
13. Visual/dashboard filters and slicers.
14. Interactive cross-filtering.
15. PDF/PNG/SVG/CSV/XLSX export as appropriate.
16. Local settings, recent projects, source relinking and secure local connection profiles.
17. Windows, macOS and Linux installable builds.
18. No cloud dependency, account, telemetry or Central integration.
